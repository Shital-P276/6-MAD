
# Muze 

[![Language](https://img.shields.io/badge/language-Kotlin-purple.svg)](https://kotlinlang.org/)

**Muze** is an Android application developed as the official course project for the Mobile Application Development (MAD) lab. 

The application is hosted online, where you can explore its interface, features, and target workflows directly from the web landing page.

🔗 **Live Website & Download Link:** [https://getmuze.netlify.app/](https://getmuze.netlify.app/)

---

## 📌 Project Overview
This repository contains the source code and development history for **Muze**. Built entirely using Kotlin, this app serves as a practical implementation of modern Android development principles studied throughout the academic course.

### Key Highlights:
* **Course Assignment:** Designed and built to fulfill experimental milestones and structural requirements for the MAD curriculum.
* **Interactive Design:** Explores custom UI elements, multi-activity navigation, and backend event handling.
* **Web Portal:** Features, application overviews, and direct download packages are hosted seamlessly on Netlify for easy deployment tracking.

## 🛠️ Tech Stack & Lab Progression
The project tracks standard incremental development phases across several lab milestones:
* **Language:** 100% Kotlin
* **Architecture Components:** Activities, Intent handling, Date-time pickers, and custom UI components.
* **Lab History:** Progressed systematically through standalone modular assignments (`lab1-27jan`, `lab2-3feb`, etc.) to the unified application package.
